### Tips for consistency across a full shoot
- Generate all frame/hero/front/side shots in the *same session or with the same seed* where your tool supports it — this keeps the amber tint and titanium tone consistent across images.
- If a tool lets you upload a reference image, use the SVG exports from this pack (`hero-three-quarter-view.png`, `front-view.png`) as a shape/composition reference so the "real" photo matches the actual concept design rather than the AI inventing a different silhouette.
- Avoid the word "futuristic" or "sci-fi" in prompts — it consistently pushes generators toward bulky AR/VR-goggle looks, which is exactly what this brief wants to avoid.
